ARCHIVE SUMMARY
---------------
This package contains a complete, self-contained offline mirror of the
authorised website https://varanasitemples.in/ and six comprehensive,
curated deity-specific pilgrimage guides with geographic zone routing.

It is designed to work 100% offline without requiring internet access,
specifically tailored for use on Android smartphones, tablets, and laptops
during pilgrimages through the narrow alleys (galis) of Varanasi.

DELIVERABLE CONTENTS
--------------------
1. DELIVERABLE A — EXACT OFFLINE WEBSITE MIRROR (Folder: Kashi_Exact_Offline_Website/)
   - index.html: Homepage of the mirror.
   - category/: All 321 temple category pages with full articles.
   - All individual post permalinks, hubs, and guides.
   - assets/css/: Local stylesheets (style.css, etc.).
   - assets/js/: Local scripts (jQuery, collapsing categories navigation, etc.).
   - assets/images/: All 326 downloaded temple photographs, deity images, and theme assets.
   - data/: Complete audit manifests (crawl_manifest.csv, crawl_manifest.json, visited_urls.txt, etc.).
   - local_server.py: Zero-dependency local HTTP server script for Android Termux or desktop.

2. DELIVERABLE B — CURATED PILGRIMAGE GUIDES (Root Directory)
   - Kashi_Pilgrimage_Master_Index.html: Interactive offline portal with search, zone filters, and 4-day itinerary.
   - 01_Surya_Dwadasa_Aditya.html: All 12 Dwadasha Aditya shrines in Kashi.
   - 02_Bhairav_Temples.html: Kaal Bhairav and the 8 protector Bhairav shrines (Ashtabhairava).
   - 03_Devi_and_Dashamaha_Vidya.html: 32 Prominent Devi shrines including Dashamaha Vidya research analysis.
   - 04_Shiva_and_Kashi_Jyotirlingas.html: Main Shiva temples & all Kashi Jyotirlinga counterparts.
   - 05_Vinayaka_Temples.html: Prominent Vinayaka shrines (Dhundhi, Bada Ganesh, 56 Vinayakas).
   - 06_Vishnu_Temples.html: Prominent Vishnu shrines (Adi Keshav, Bindu Madhav, Narasimha, Varaha).
   - temples_master.csv / temples_master.json: Structured database exports of all temples.
   - missing_data_report.csv / missing_images_report.csv: Exhaustive data gap & asset reports.

HOW TO USE ON ANDROID PHONE (OFFLINE)
-------------------------------------
METHOD 1: DIRECT BROWSER OPENING (Easiest)
1. Copy this entire unzipped folder to your phone's Internal Storage or SD card (e.g. into Documents/Kashi_Guide/).
2. Open any web browser on your phone (Chrome, Firefox, Samsung Internet, Kiwi Browser).
3. Open files directly using the file manager or type in browser:
   file:///sdcard/Documents/Kashi_Guide/Kashi_Pilgrimage_Master_Index.html
   or
   file:///sdcard/Documents/Kashi_Guide/Kashi_Exact_Offline_Website/index.html
4. Bookmark the Master Index in your browser for instant one-touch access during your yatra.

METHOD 2: LOCAL WEBSERVER VIA TERMUX (Recommended if phone browser restricts file://)
1. Install Termux (free from F-Droid or GitHub).
2. Inside Termux, navigate to the folder:
   cd /sdcard/Documents/Kashi_Guide/Kashi_Exact_Offline_Website
3. Run the local server:
   python local_server.py
4. Open http://localhost:8080 in Chrome on your phone.

METHOD 3: HTML VIEWER APP
1. Use an offline HTML reader app like "HTML Viewer" or "Offline Browser" available on Google Play Store.

GEOGRAPHIC ZONING METHODOLOGY
-----------------------------
To minimize backtracking across Varanasi's riverfront and densely packed lanes,
temples are classified into four geographic zones based on verified location evidence:
- North Kashi: Trilochan, Panchganga, Rajghat, Maidagin, Chaukhamba, Machhodari, Adampura.
- South Kashi: Assi, Shivala, Kedargeshwar, Sonarpura, Lolark Kund, Bhelupur, Durgakund.
- East Kashi (Riverfront & Ghats): Dashashwamedh, Manikarnika, Mir Ghat, Rana Mahal, Tripurabhairavi.
- West Kashi: Chowk, Vishwanath Gali, Bansphatak, Gyanvapi, Lahurabir, Pisachmochan.
